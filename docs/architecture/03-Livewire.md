# Livewire

## Responsibilities

- Forms
- Search
- Filter
- Pagination
- Modal
- UI Interaction

---

## Forbidden

- Heavy Query
- Accounting Logic
- Payroll Calculation
- Inventory Costing

---

## Rules

Livewire

↓

Service

↓

Repository

Never

Livewire

↓

Model

↓

Complex Query

---

## Validation

Always use Form Objects or Validation Rules.

One Component = One Responsibility
